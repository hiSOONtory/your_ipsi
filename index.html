학생 성적 입력

필수 열: 학생ID, 학년, 학기, 교과, 과목명, 학점, 석차등급, 성취도 · 선택 열: 원점수, 과목평균, 수강자수, A비율, B비율, C비율 (0~1) · 엑셀(.xlsx) 또는 CSV 파일을 업로드하세요. 학생ID에 실명을 사용하지 마세요 — 번호나 별칭을 권장합니다.

"추가 반영"은 기존 데이터에 합칩니다(반 추가 시). "전체 교체"는 기존 성적 데이터를 지우고 새로 넣습니다.

반 전체 진단표

열 제목을 클릭하면 정렬됩니다. "상담" 버튼을 누르면 개별상담 화면으로 이동합니다. (수능최저 게이트는 개별상담에서 모의고사 등급 입력 후 확인)
